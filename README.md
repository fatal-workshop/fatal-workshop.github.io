# 2nd FATAL Workshop

**FATAL = Friends And Talks At Lunch**

Static website for the UC3M–UPM FATAL Workshop.

## Publish with GitHub Pages

1. Create a repository in the `fatal-workshop` GitHub account (for example, `fatal-workshop.github.io`).
2. Upload `index.html` and `styles.css` to the repository root.
3. If the repository is named `fatal-workshop.github.io`, GitHub Pages should publish it as the account site. Otherwise, enable GitHub Pages under **Settings → Pages**, using the `main` branch and `/ (root)` folder.

## Edit the programme

Open `index.html` and search for:

- `TBA` to set date and venue.
- `speaker-list` to add UC3M speakers.
- `UPM` / `Speakers to be announced` to add the UPM list.

## Logos

The current page loads the UC3M and UPM marks from Wikimedia Commons so the repository stays lightweight. If you prefer, replace those image URLs with locally stored institutional logo files (e.g. `assets/uc3m.svg` and `assets/upm.svg`).
